💡 How to Use Smart Search

1. Search Specific Fields

Format: fieldname:value

Example: status:Deployed or department:IT

2. Find Empty / Blank Fields

Format: fieldname:empty or fieldname:blank

Example: bitlocker_key:empty or notes:blank

3. Search Files & Images

Search attached images or uploaded documents by name, extension, or missing status.

Examples: images:empty, images:png, or forms:pdf

4. Exact Phrase Search

Use double quotes for multi-word terms.

Example: job_title:"Systems Engineer"

5. Combine Conditions (OR Logic)

Use OR between queries.

Example: status:Available OR status:"In Repair"

Tip: Standard text search without field names still searches across all visible columns simultaneously.
